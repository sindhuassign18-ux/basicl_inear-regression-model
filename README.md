# basicl_inear-regression-model
A beginner-friendly Linear Regression project that predicts sepal length from petal length using Python and Scikit-learn.

This project implements a Linear Regression machine learning model using Python and Scikit-learn. The model is designed to learn the relationship between petal length (`petal_L`) and sepal length (`sepal_L`) from a flower dataset. The problem it solves= Can I predict Sepal length If I know the Petal Length

The dataset is first loaded and prepared using Pandas. The data is then divided into training and testing sets using `train_test_split()`. The Linear Regression model learns a linear relationship from the training data and uses it to predict sepal length for unseen test data.

The model's predictions are compared with the actual values using Mean Squared Error (MSE) to evaluate its performance. A scatter plot with the regression line is also created to visually represent the relationship between petal length and sepal length.

This project demonstrates the basic machine learning workflow of data preparation, model training, prediction, evaluation, and visualization.
